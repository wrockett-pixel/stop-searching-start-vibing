# Stop Searching, Start Vibing

Interactive presentation for GaETC 2026 by Lindsay Whiteman and Wendy Rockett, Forsyth Virtual Academy.

- `docs/` is the published website (GitHub Pages and Netlify publish this folder).
- `apps-script/check-in-sheet.gs` is the Google Apps Script behind the live "Who's in the room?" check-in. Paste it into a Google Sheet's Apps Script and deploy it as a web app. Set your own PIN there, not in this repository.
